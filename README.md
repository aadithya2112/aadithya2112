<details>
  <summary><strong>How I think about a production system</strong></summary>
  <br />

```mermaid
flowchart LR
    A[Typed product] --> B[Secure API]
    B --> C[(Durable state)]
    B --> D[Queue]
    D --> E[Isolated worker]
    E --> C
    C --> F[Live updates]
    F --> A
    E --> G[Artifacts + logs]
```

<p>The details change. The habits do not: explicit contracts, durable state, bounded retries, useful logs, and a UI that tells the truth.</p>
</details>
